2. Чужие материалы
------------------
Лаунчер — это установщик. Моды, программы, модели и голоса других авторов не входят в
программу: он скачивает их на ваш компьютер в момент установки. На них настоящая лицензия не
распространяется — каждый остаётся под лицензией своего автора, и вы получаете его на её
условиях. Подписка на Boosty даёт доступ только к программе AD.Lindel: всё перечисленное ниже
лежит в открытом доступе, бесплатно и без регистрации, и автор лаунчера платы за это не берёт.

2.1. С источников авторов лаунчер берёт:
  • SkyrimNet (MinLL) и моды-спутники к нему SeverActions (Severause) и IntelEngine (galanx) —
    с GitHub. Открытой лицензии у них нет, поэтому лаунчер их нигде не хранит: он скачивает их
    с выпусков авторов, а свои правки применяет у вас на компьютере после установки;
  • SKSE64 и SKSEVR — с сайта авторов;
  • Address Library for SKSE Plugins, powerofthree's Papyrus Extender, PapyrusUtil,
    JContainers, UIExtensions, SkyUI, Backported Extended ESL Support (BEES), Media Keys Fix,
    FonixData — с Nexus Mods;
  • VR Address Library, Skyrim VR ESL Support, SkyUI VR, Prisma UI, Native EditorID Fix,
    powerofthree's Tweaks (GPL-3.0), Mfg Fix NG (GPL-3.0), Mod Organizer 2 (GPL-3.0) — с GitHub;
  • Microsoft Visual C++ Redistributable — с сайта Microsoft, ставится её же установщиком;
  • модели распознавания речи Whisper (MIT) — с Hugging Face (ggerganov/whisper.cpp);
    модель поиска по смыслу all-MiniLM-L6-v2 (Apache-2.0) — с Hugging Face;
  • Ollama (MIT) — с GitHub; модели нейросети Ollama скачивает сама из своего каталога, у
    каждой модели своя лицензия. К LM Studio, llama.cpp и KoboldCpp лаунчер только
    подключается, если они у вас уже запущены, и не ставит их.

2.2. Часть файлов лаунчер берёт с наших зеркал — открытых копий, которые автор лаунчера
держит, чтобы установка не вставала, когда источник недоступен, режет скорость или упирается
в дневной лимит: датасет Hugging Face Archidexter/adlindel-assets, выпуск models-v1 на GitHub
и Google Drive. Там лежат:
  • Mantella (mantella/SSE_Lindel_Mantella.7z) в нашей сборке из открытых исходников:
      – игровая часть — из art-from-the-machine/Mantella-Spell (MIT), исходники скриптов лежат
        рядом со скриптами; плагин SKSE_HTTP — из выпуска Leidtier/SKSE_HTTP (MIT);
      – программа — из art-from-the-machine/Mantella (GNU AGPL-3.0), с нашими правками и
        голосами Piper; её полные исходники и список наших правок («НАШИ ПРАВКИ.txt») лежат в
        том же архиве, в папке sources рядом с программой;
  • XTTS — сервер озвучки: неизменённая сборка langfod/skyrimnet-tts v0.1.10
    (https://github.com/langfod/skyrimnet-tts; основа — coqui-ai-TTS, MPL-2.0), веса модели
    Coqui XTTS-v2 (Coqui Public Model License 1.0.0) и наши образцы голосов для русской речи;
  • OmniTTS — сервер озвучки: jagerius/OmniTTS, модель k2-fsa/OmniVoice (код — Apache-2.0,
    веса — CC BY-NC), встроенный Python (лицензия PSF) и наш мост к SkyrimNet;
  • русские голоса Piper для SkyrimNet — готовые модели rhasspy/piper-voices под другими
    именами: irina (данные RHVoice) и ruslan (корпус RUSLAN, CC BY-NC-SA 4.0), с данными
    espeak-ng (GPL-3.0);
  • модели Whisper small, large-v3 и large-v3-turbo (MIT) и модель all-MiniLM-L6-v2
    (Apache-2.0) — копии без изменений, сверенные с официальным источником;
  • Ollama — неизменённая копия архива разработчика (MIT), текст лицензии лежит рядом.

2.3. Только некоммерческое использование разрешают: модель XTTS-v2 (Coqui Public Model
License), модель OmniVoice (CC BY-NC), голос Piper ruslan (CC BY-NC-SA 4.0) и голос irina

    the all-MiniLM-L6-v2 embedding model (Apache-2.0) — from Hugging Face;
  • Ollama (MIT) — from GitHub; Ollama downloads the AI models itself from its own library, and
    each model has its own license. LM Studio, llama.cpp and KoboldCpp are only connected to if

  • Mantella (mantella/SSE_Lindel_Mantella.7z), our build from the open sources:
      – the game part from art-from-the-machine/Mantella-Spell (MIT), with the script sources next
        to the scripts; the SKSE_HTTP plugin from the Leidtier/SKSE_HTTP release (MIT);
      – the program from art-from-the-machine/Mantella (GNU AGPL-3.0), with our changes and Piper
        voices; its complete sources and the list of our changes ("НАШИ ПРАВКИ.txt") are in the
        same archive, in the sources folder next to the program;
  • XTTS — a voice server: the unmodified langfod/skyrimnet-tts v0.1.10 build
    (https://github.com/langfod/skyrimnet-tts; based on coqui-ai-TTS, MPL-2.0), the Coqui XTTS-v2
    model weights (Coqui Public Model License 1.0.0) and our voice samples for russian speech;
  • OmniTTS — a voice server: jagerius/OmniTTS, the k2-fsa/OmniVoice model (code Apache-2.0,
    weights CC BY-NC), an embedded Python (PSF license) and our bridge to SkyrimNet;
  • russian Piper voices for SkyrimNet — stock rhasspy/piper-voices models under other names:
    irina (RHVoice data) and ruslan (RUSLAN corpus, CC BY-NC-SA 4.0), with espeak-ng data

  • the Whisper small, large-v3 and large-v3-turbo models (MIT) and the all-MiniLM-L6-v2 model

  • Ollama — an unmodified copy of the developer's archive (MIT), with the license text next to it.
